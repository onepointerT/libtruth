Detailed Description

template<typename T = BoolValue>
requires is_bool_evaluatable< T >
class truth::BoolDict< T >

A bool value dict. The truth values are ordered by a const std::string, for example for correspondence with coherent univarite variable names.

Template Parameters
TThe type of bool truth values to save in the dict for the key values. Defaults to T = BoolValue.
